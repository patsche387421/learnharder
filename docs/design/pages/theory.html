Klassen in Python

Eine Klasse ist ein Bauplan für Objekte. Sie definiert Attribute (Daten) und Methoden (Verhalten).

§1 Was ist eine Klasse?

Eine Klasse ist eine Vorlage oder ein Bauplan zum Erstellen von Objekten. Sie bündelt zusammengehörige Daten (Attribute) und Funktionen (Methoden) in einer logischen Einheit. Objekte, die nach einer Klasse erstellt werden, nennt man Instanzen.

Python 
class Auto:
    def __init__(self, marke, baujahr):
        self.marke = marke
        self.baujahr = baujahr

    def beschreibung(self):
        return f"{self.marke} ({self.baujahr})"

# Instanz erstellen
mein_auto = Auto("VW Golf", 2023)
print(mein_auto.beschreibung())
# Ausgabe: VW Golf (2023)
Merksatz
Klasse = Bauplan. Objekt = fertiges Ding. Mit __init__ wird jedes neue Objekt initialisiert.

§2 Attribute vs. Methoden

Attribute

Variablen, die zu einem Objekt gehören. Definiert in __init__ mit self.x

self.name self.alter
Methoden

Funktionen innerhalb einer Klasse. Immer mit self als erstem Parameter

def reden() def info()

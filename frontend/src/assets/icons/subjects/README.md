# Fächer

Illustrierte Fach-Icons: eine abgerundete Kachel mit einem Verlauf in der Fachfarbe (`subject-*`) und einem hellen Motiv. viewBox 48×48.

- `subject-<kürzel>.svg`: ohne Text. Für Listen, Karten und alle Größen unter 64px. Bei 32px erkennbar.
- `subject-<kürzel>-label.svg`: mit Kürzel-Label (Space Mono Bold), nur ab 64px, z. B. im Kopf einer Fach-Seite.

| Fach | Motiv | Farbe |
|---|---|---|
| POS | Terminal-Fenster | `subject-pos` |
| DBI | Datenbank-Zylinder | `subject-dbi` |
| NSVS | Netzwerk-Knoten | `subject-nsvs` |
| TINF | Mikrochip mit „01“ | `subject-tinf` |
| WIR | Steigendes Balkendiagramm | `subject-wir` |
| MEDT | Filmklappe | `subject-medt` |
| SYP | Kanban-Board | `subject-syp` |

Einbinden mit `<img>` und einem `alt`-Text mit dem vollen Fachnamen. Neue Fächer folgen demselben Aufbau.
